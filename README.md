# OpenAIGlobalSentiment
I was curious about how public opinion around OpenAI has changed over time, given the hot discourse that currently surrounds artificial intelligence.

To answer my questions, I wrote this program that extracts sentiment data about OpenAI from news articles written in a variety of languages from a plethora of places. The data are then written onto a csv file for further analysis/visualization in your preferred software.

## How to use:
Select desired source language from dropdown menu, then click "Write csv".
