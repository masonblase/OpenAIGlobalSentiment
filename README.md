# OpenAIGlobalSentiment
Given the hot discourse that currently surrounds artificial intelligence, I was curious about what the public opinion on OpenAI is and how it changes with each new release/controversy that hits the company.

To answer my questions, I wrote this program that extracts sentiment data from news articles about OpenAI written in the past month in a variety of languages and from a plethora of places. The data are then written onto a csv file for further analysis/visualization in your preferred software.

Businesses operating with a paid NewsAPI plan can fetch articles up to 5 years old, facilitating analyses of sentiment change over a long period of time.

## How to use:
Select desired source language from dropdown menu, then click "Write csv".
